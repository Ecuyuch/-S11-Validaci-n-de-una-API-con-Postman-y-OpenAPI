# Evidencia

Esta carpeta se llena al ejecutar **en tu equipo**:

```powershell
npm run evidence     # genera 01-fallo-controlado.* y 02-correccion.*
npm run collection   # genera latest-collection-result.json (API iniciada con npm start)
```

Los archivos generados son la evidencia que debes citar en el README y en el PDF de Canvas.
No se incluye evidencia pre-generada: debe provenir de tu propia ejecución.
